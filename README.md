# Личный бюджет

Итоговое ДЗ по TypeScript: консольное приложение для учёта личных денег. Меню и ввод работают через `inquirer`, все суммы – в рублях.

## Как запустить

Нужны Node.js 20.18 или новее и npm. Из папки проекта выполни:

```bash
npm ci
npm start
```

Первая команда установит зависимости, вторая соберёт проект и откроет меню в терминале.

## Что умеет

- Создавать счета с уникальными ID и показывать их баланс.
- Добавлять доходы и расходы, просматривать список транзакций.
- Удалять транзакции и счета с подтверждением.
- Выгружать операции выбранного счёта в CSV.
- Сохранять данные между запусками.

## Как пользоваться

Выбирай пункты стрелками ↑/↓ и нажимай Enter. Для подтверждения введи `y`, для отмены – `n`. Просто Enter тоже означает «нет». Выйти можно через меню или `Ctrl+C`.

Сумму вводи положительной, например `1500` или `1500,50` – точка тоже подходит. Для расхода выбери соответствующий тип операции. Дата вводится в формате `ГГГГ-ММ-ДД`, например `2026-10-31`. Если данные неверные, приложение подскажет, что исправить.

## Где лежат данные

Счета и транзакции сохраняются в `data/accounts.json`, CSV-файлы – в `exports/`. Папки создаются автоматически внутри каталога, из которого запущено приложение. Запускай один экземпляр приложения за раз, чтобы записи не перезаписывали друг друга.

## Проверка

```bash
npm run check
```

Команда проверяет TypeScript и запускает все тесты. Посмотреть покрытие можно через `npm run test:coverage`.

## Что внутри

`Account` и `Transaction` отвечают за счета и операции, `AccountManager` управляет ими, а `ApplicationController` – меню. Работа с JSON и CSV вынесена отдельно. Деньги хранятся в копейках, чтобы расчёты были точными.
